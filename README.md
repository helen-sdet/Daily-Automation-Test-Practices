# Daily Automation Test Practices

## Description
This repository contains daily automation testing practices using Java and Postman for API testing. I share step-by-step backend tests to ensure reliability and accuracy in the development process.

## Technologies Used
- Java
- Postman
- AWS
- SQL

## Installation
1. Clone this repository to your local machine.
2. Ensure you have Java and Postman installed.
3. Run your API tests using Postman collections and Java-based test scripts.

## Example Tests
You can find example API tests in the `tests` folder. Each test checks specific endpoints, verifying response status and data integrity.
